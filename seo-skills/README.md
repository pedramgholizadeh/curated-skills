# SEO Skills

Search engine optimization as an engineering and content discipline: content,
on-page signals, and whole-site optimization.

## Stacks

| Stack | Scope |
|---|---|
| [content-skills/](content-skills/README.md) | Keyword research, content writing, content strategy |
| [on-page-skills/](on-page-skills/README.md) | Meta tags, structured data, internal linking |
| [optimizing-website/](optimizing-website/README.md) | Technical SEO, Core Web Vitals, performance audits |

## Layout

```
seo-skills/
└── <stack>/<subcategory>/<skill-name>/SKILL.md
```

Each subcategory folder carries a `README.md` describing its scope. See the
root [README.md](../README.md) for usage and
[CONTRIBUTING.md](../CONTRIBUTING.md) for the quality bar.
