# Reel Grammar

The repeatable story spine behind every brand reel. This is the "what's what" layer: which scene to reach for, and how to write its copy.

## The arc

`hook → problem → solution (features | compare) → belief (statement) → process (features) → cta`

You rarely need all six. Pick 4–7 scenes that carry the arc. Always: **open on a hook, close on the CTA.**

## Scene archetypes

### `hook` — the 3-second job
The single most important scene. Its only goal is to stop the thumb. Formula:

> **A controversial, specific question that names the viewer's actual problem.**

- Phrase it as a question ending in the locale's question mark (`?`, `؟`, `¿`…).
- Name the pain, not the brand. No company name here.
- ≤ 2 short lines. Emphasize the one loaded word (color + weight bump).
- Optional single icon above the text for instant context.

Good: "Still paying for ads that *stop* when the budget does?"
Bad: "Welcome to Acme Marketing" (brand-first, no tension).

### `problem` — agitate
One title line + two short lines of concrete pain. Pull from the page's own "why this hurts" copy.

### `features` — deliver (complementary set)
A head line + 3–5 cards. Each card: `text` (the benefit), `detail` (one clause of proof), `icon`. Exactly one card may be `accent` (the differentiator). Use when the parts are **all delivered together** (a methodology, a bundle, a process).

### `compare` — choose (alternative set)
Same card data as `features`, but the engine draws a circular **VS** chip between rows. Use **only** when the viewer *picks between* mutually-exclusive options (product tiers as categories, service types, plan *kinds* — never plan *prices*). One row may be `accent`.

Decision rule — features vs compare:
- "Do these solve it *together*?" → `features`.
- "Does the customer *choose one*?" → `compare`.

### `statement` — the belief
Two or three big centered lines, no cards. A breather that lands a point of view. Use between card-heavy scenes to vary rhythm.

### `cta` — the close
Deliberately simple: small logo → the **domain typed** with a caret → one contact line. On every reel the contact line is the same shape, localized: *"For a free consultation, just DM us."* No pills, no clutter, no numbers.

## Copy extraction (from real content)

1. Open the business's landing page JSON/HTML. Collect: H1 (the promise), H2s (the sections), H3s (value props / types / steps), body blocks (proof clauses).
2. Map them to scenes:
   - the sharpest pain → `hook`
   - "why it matters" → `problem`
   - "what we do" list → `features`
   - "types / variants" list → `compare`
   - "how it works / process" → `features` (steps)
   - a quotable belief → `statement`
3. Rewrite into ≤ 2-line, glanceable phrases in the brand's voice. Keep the meaning, drop the marketing filler.

## Hard content rules

- **No numbers, counts, or prices.** Do not surface "N pages", "N months", "from $X", follower counts, or testimonials. Marketing reels that quote specifics rot and mislead; keep the message durable.
- **No invented claims.** Every line must trace to real business content.
- **Locale-correct text:** native digits, real half-spaces / NBSP, no emoji rendered on canvas (draw icons from the icon font instead).
- **One idea per line.** If a line needs a comma to breathe, it's two lines.

## Duration budget

| Scene | Seconds |
|---|---|
| hook | 3 |
| problem | 4 |
| features / compare | 6 |
| statement | 3–4 |
| process (features) | 4–6 |
| cta | 5 |

Target total ~26–30s; hard ceiling 60s. Entrance animation must finish well before the scene's midpoint so the text is fully readable while it holds.
