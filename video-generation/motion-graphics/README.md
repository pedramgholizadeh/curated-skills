# Motion Graphics Skills

Skills for designed motion: type, data, and titles.

## Typical skill topics

- Kinetic typography systems and timing curves
- Animated charts and data callouts
- Title sequences and lower thirds
- HTML/CSS/SVG timeline animation with brand tokens
