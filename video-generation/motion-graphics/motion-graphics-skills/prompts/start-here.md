# Start here

The one line that gets you a motion graphic in about 60 seconds, and the way to change it once it exists.

## The one-line starter

Paste this into Claude Code on Opus 5.5 before you install anything else. It writes the animation as code, draws every frame, then turns the frames into an MP4.

```
Make a dynamic 15-second motion graphics video that shows what an incredible motion designer you are. Go all out.
```

On a fresh Claude Code it picks its own colours, type and idea of motion. Once you have a brand design system (see [brand-design-system.md](brand-design-system.md)), the same line comes out in your brand.

## Edit it by describing the change

You never touch the code. Say what you want different, one change at a time.

Use this when one part runs too fast:

```
Slow down the second scene.
```

Use this to put your own words in:

```
Swap the text for mine.
```

Use this when the text needs to be specific:

```
Swap the text for mine: [your words].
```

Use this to change one colour for another:

```
Make the orange navy.
```

Use this before you have a MOTION.md:

```
Use my brand colours: [hex codes].
```

Use this when it is going on LinkedIn:

```
Make it 1080 x 1350 for LinkedIn.
```

## Do this tonight

1. **Build your brand design system first.** Save five frames of motion you love (Dribbble and Pinterest are full of them) and run the design system prompt in [brand-design-system.md](brand-design-system.md). Your brand design system is everything. Get it right and the model does most of the heavy lifting.
2. **Then paste the one-line prompt above** and watch what comes back.
3. **Not on Claude Code yet?** [Start there instead](https://charliehills.substack.com/p/give-me-10-minutes-ill-teach-you), then come back to this.
