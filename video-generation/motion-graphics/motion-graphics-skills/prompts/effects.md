# The 16 effects, one prompt each

Each prompt builds one effect from scratch, in your brand, as a single `effect.html` that loops every 8 seconds and exports to MP4 frame for frame. Fill in the square brackets and paste it into Claude Code.

They work on their own. With the `motion-effects` skill installed, Claude also reads the full recipe for that effect (the exact timing and the detail that makes it look premium) and checks its own frames before it shows you.

Run `brand-intake` first so Claude has your MOTION.md. Without it, every prompt below comes back in Claude's colours, not yours.

## Interfaces: show your product doing something

### 01 Button → player

Use this to add a "watch the demo" moment to a landing page or launch email.

```
Read MOTION.md first. Build effect.html from scratch: a small pill button labelled [BUTTON TEXT] grows into a full video player titled [VIDEO TITLE], with a thumbnail, a time readout and a progress bar. The play icon travels to the centre and turns into pause. One 8-second loop with window.seek(seconds), ending exactly where it starts. Size: [SIZE]. Embed the fonts.
```

## When it is close but not right

Name one thing at a time. It gets you there faster, and it stops Claude changing the motion you liked.

```
effect.html is close. Fix one thing only: [what looks wrong, e.g. the headline runs past its box at 3 seconds]. Keep the motion, the timing and the loop exactly as they are. Tell me what you changed.
```
