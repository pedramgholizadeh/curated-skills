# 📐 Claude Motion Graphics Skills (vendored)

Fifteen brand-aware motion-graphics skills, vendored as contributed by Ahmad Mousavi.

Upstream: [charlie947/motion-graphics-skills](https://github.com/charlie947/motion-graphics-skills) · [ahmadmousavi.ir](https://ahmadmousavi.ir)

Everything is built in code (HTML + canvas/Three.js rendered frame by frame), loop-safe,
and sized for the feed it will land in. Start with `brand-intake`: every other skill in
the pack reads the brand file it produces.

## Skill index

| Skill | One-line job |
|---|---|
| [brand-intake](brand-intake/SKILL.md) | Interview + 3–5 reference frames → the brand file every other skill reads. |
| [motion-brief-writer](motion-brief-writer/SKILL.md) | Rough idea → precise build brief in your brand. |
| [motion-prompt-writer](motion-prompt-writer/SKILL.md) | Writes the complete 8-part motion prompt. |
| [reference-to-motion](reference-to-motion/SKILL.md) | Clip you admire → scene-by-scene prompt for your own topic. |
| [motion-effects](motion-effects/SKILL.md) | Any of 16 premium effects as one 8-second looping HTML file. |
| [animated-chart](animated-chart/SKILL.md) | Looping animated chart for LinkedIn or a newsletter. |
| [milestone-reveal](milestone-reveal/SKILL.md) | 12-second looping milestone clip (particle field → number). |
| [loop-cover](loop-cover/SKILL.md) | Blog/newsletter cover → seamless 896×640 looping GIF. |
| [newsletter-promo](newsletter-promo/SKILL.md) | Newsletter edition → 12–20 s promo clip. |
| [launch-video](launch-video/SKILL.md) | 30–45 s SaaS launch video. |
| [apple-launch-film](apple-launch-film/SKILL.md) | Apple-style launch film rebuilt in code. |
| [title-sequence-3d](title-sequence-3d/SKILL.md) | 8–15 s cinematic 3D title sequence (Three.js). |
| [vox-explainer](vox-explainer/SKILL.md) | 30–60 s Vox-style documentary explainer. |
| [model-showdown](model-showdown/SKILL.md) | Same brief → three models, first tries, side by side. |
| [reel-export](reel-export/SKILL.md) | Horizontal/square motion video → clean 1080×1920 Reel. |
