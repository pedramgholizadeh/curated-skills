# AI Video Generation Skills

Skills for generative video: text-to-video and image-to-video workflows.

## Typical skill topics

- Prompt writing for motion, camera movement, and style consistency
- Keyframe/first-frame strategies for image-to-video
- Shot-to-shot continuity and character consistency
- Tool-specific workflows (Veo, Runway, Kling, and agent video tools)
