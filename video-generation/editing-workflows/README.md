# Video Editing Skills

Skills for working with existing footage rather than generating it.

## Typical skill topics

- Programmatic cutting, trimming, and concatenation (FFmpeg)
- Subtitle burning, audio replacement, and normalization
- Aspect-ratio conversions for vertical (9:16) reels
- Color, exposure, and stabilization pass decisions
