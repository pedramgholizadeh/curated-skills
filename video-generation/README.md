motion graphics, editing, and generative workflows.

| [motion-graphics/](motion-graphics/README.md) | Kinetic typography, animated charts, titles |
| [editing-workflows/](editing-workflows/README.md) | Cutting and compositing existing footage |
| [ai-video-generation/](ai-video-generation/README.md) | Text/image-to-video generation with AI tools |
