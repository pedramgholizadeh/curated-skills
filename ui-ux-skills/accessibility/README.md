## Typical skill topics

- WCAG 2.2 compliance audits (perceivable, operable, understandable, robust)
- ARIA roles, states, and when NOT to use ARIA
- Keyboard navigation and focus management
- Screen reader testing workflows (VoiceOver, NVDA)
