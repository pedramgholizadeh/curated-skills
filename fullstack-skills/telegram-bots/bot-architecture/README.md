- Conversation and menu flow design (inline keyboards, callbacks, FSMs)
- Telegram Stars / payments and subscription gating
- Multi-tenant bots, admin panels, and broadcasting at scale
- Anti-abuse: flood control, spam handling, update idempotency
- Mini App (TMA) front-end integration and auth verification
