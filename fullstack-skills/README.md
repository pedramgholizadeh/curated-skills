# Fullstack Skills

Production skills for building complete applications: servers, web clients,
mobile apps, Telegram bots, and AI agents.

## Stacks

| Stack | Scope |
|---|---|
| [backend/](backend/README.md) | Node.js, Python, Go, databases, API design, auth, testing, deployment |
| [frontend/](frontend/README.md) | React/Next.js, Vue/Nuxt, TypeScript, styling, performance, testing |
| [mobile/](mobile/README.md) | React Native, Flutter, iOS (Swift), Android (Kotlin) |
| [telegram-bots/](telegram-bots/README.md) | Python and Node.js bot frameworks, conversation and scaling patterns |
| [ai-agents/](ai-agents/README.md) | LLM integration, RAG, MCP servers, orchestration, evaluation |

## Layout

```
fullstack-skills/
└── <stack>/<subcategory>/<skill-name>/SKILL.md
```

Each subcategory folder carries a `README.md` listing the skills it contains
and the ones planned for it. See the root [README.md](../README.md) for how to
install and use skills, and [CONTRIBUTING.md](../CONTRIBUTING.md) for the
quality bar.
